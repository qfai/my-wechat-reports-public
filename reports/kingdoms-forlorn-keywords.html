Reference · 复杂关键词详解

Drag X / Drag toward

Drag X：先让来源沿远离目标的直线移动至多 X 格，再让目标沿来源刚走过的路径移动 X 格；结束时来源转向受影响模型。若来源是非 Mob Monster，被拖拽的 Knight 可穿过其他模型；非自愿移动结束在被占空间时，原占位模型 Displace。若来源是 Mob Monster 或 Knight，在来源将进入被占空间前停止。目标结算沿途地形：拖入 Destructible Obstacle 时移除地形、Knight 遭受 Crash，然后继续；拖入 Indestructible Obstacle 时 Knight 遭受 Crash，Drag 停止。Knight 可在第一或第二能力窗口使用。
Drag toward：来源不再笔直远离目标，而是沿最短路径朝指定空间移动并越过该空间，直到目标能够进入指定空间，或来源已移动至 Drag 数值上限；之后目标沿来源路径移动，直到与来源相邻。

Herd X

来源先朝目标移动至多 X 格；再让目标 Knight 使用剩余格数，忽略来源，沿最短路径朝另一个最近 Monster 移动，或移动到与其相邻为止，视为非自愿移动。若目标已与另一个 Monster 相邻，改为遭受 Knockdown。最后来源一定移动到目标相邻。若目标将结束在来源占据的空间，把来源 Displace 到 Knight 刚经过的前一格。源文件说明：规则框一处把“另一个 Monster”排成了“another Knight”；结合前句与示例，此处按 Monster 解释。

Knockback X

把受影响模型沿远离来源的直线移动至多 X 格；Directional Knockback 则沿指定方向。由 Attack 造成时，只有目标仍在攻击有效范围内才生效；由 Knight 造成时，目标须相邻或处于当前武器有效范围；由 Monster Response 造成时，仅影响相邻攻击者。Knight 忽略沿途所有非 Obstacle 地形；撞上 Destructible Obstacle 时停下、移除地形、站到其空间并遭受 Crash；撞上 Indestructible Obstacle 时停在障碍前相邻格并遭受 Crash。Monster 可穿过地形和模型，摧毁其落脚的 Destructible Terrain；Boss Monster 仍会对沿途 Knight 造成 Crash 与 Unavoidable Knockback。撞到另一个 Knight 时，按非自愿移动规则 Displace 原占位者。撞到 Board Edge 时，如可能便沿边缘继续移动，方向仍须远离来源。侧向 Knockback 改沿来源—目标直线的垂线、且确实远离来源的方向移动。

Knockdown

Knockdown 是特殊 Condition。获得 Knocked Down Condition，把模型侧放并取得 falling down 面。倒地期间不能主动移动，也不能执行 action、reaction、free action，或使用 Gear ability 与 Technique，除非规则明确允许。到你下一个回合结束时，把卡翻到 standing up 面；持有 standing up 面的 Knight 在其再下一个回合开始时站起。若该卡因任何原因被弃置，也立即视为站起。Rocksteady、Acrobatics、Roll Out 等能力会在“即将遭受 Knockdown”时替代或无效化它。

Pull X

让受影响模型沿最短路径朝来源移动至多 X 格；结束时来源转向受影响模型。被 Pull 的模型可穿过其他模型；若非自愿移动结束在被占空间，原占位模型 Displace。被 Pull 的 Boss Monster 照常对 Knight 造成 Crash。Knight 被拉入 Destructible Obstacle 时，移除地形、遭受 Crash 后继续；将进入 Indestructible Obstacle 时遭受 Crash，并沿障碍边缘以到来源的最短路径继续。目标与来源相邻时 Pull 立即结束。Knight 可在第一或第二能力窗口使用。

Pushback X / Pushback toward

Pushback X：来源先转向目标，再朝目标方向移动至多 X 格，并沿直线推动目标。若来源是非 Mob Monster，被推 Knight 可穿过其他模型；若结束在被占空间，原占位模型 Displace。若来源是 Mob Monster，在将进入被占空间前停止。推入 Destructible Obstacle 时移除地形、Knight 遭受 Crash 并继续。Boss Monster 把 Knight 推入 Indestructible Obstacle 时，先把 Knight Displace 到能让 Boss 进入其原空间的相邻格并继续；不能 Displace 则 Knight 死亡。Mob Monster 推 Knight 撞不可摧毁障碍时停止并使其 Crash；Knight 把 Mob Monster 推向不可摧毁障碍时停止，且该 Knight 遭受 Crash。推向 Board Edge 时先尝试 Displace 目标，让来源进入其原空间后继续；不能 Displace 时，来源为 Knight 或 Mob 则停止，来源为非 Mob Monster 则目标死亡。Knight 可在攻击的第一或第二能力窗口使用，但不能用于带 Ranged X–Y 的武器攻击；规则要求立即结算时不受此时机限制。
Pushback toward：不沿直线推动，改为沿最短路径把目标推向指定空间。

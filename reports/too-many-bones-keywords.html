Too Many Bones 关键词速查

敌人技能 · 状态效果 · 战斗术语 · 遭遇与恢复

依据 Chip Theory Games 官方 Rulebook、Baddie Skills Reference 与 GARG 整理 · 2026-09-15

使用说明：核心术语优先采用正式中文版规则书译名；尚未在中文版资料中确认的扩展词条为便于理解的暂译。卡牌英文关键词仍是规则判定依据。数字符号以“#”表示该技能标注的数值。

核心术语

Gearloc · 基尔洛克
玩家控制的英雄单位。每名角色拥有独立数值、技能骰子、备选方案和专属规则。
Baddie · 敌人
从敌人队列进入战斗面板的敌对单位；常按1点、5点、20点分类。
Tyrant · 暴君
冒险最终目标。通常拥有专属遭遇、暴君骰和战斗规则。
BQ · Baddie Queue · 敌人队列
尚未进入战斗面板的敌人堆。20点敌人与暴君通常放在顶部，其他敌人通常放在底部。
Ini · Initiative · 行动顺序
单位的行动顺序骰子在行动顺序条上的位置。数值越高，通常越早行动。
Dex · Dexterity · 敏捷
回合内可用于移动和投掷骰子的总点数。移动1格通常花费1敏捷。
Atk / Def · 攻击 / 防御
攻击骰子造成普通伤害；防御骰子放入主动插槽后，用于抵消之后受到的伤害。
True Dmg · 真实伤害
通常不能由防御骰抵消，直接移除生命筹码；部分技能会明确忽略真实伤害。
Fatigue · 疲劳伤害
常在回合或轮次结束时造成，通常无视防御；具体时点由遭遇或技能说明。
Exhaust · 耗尽
将骰子移至耗尽区，通常本场战斗不能再次使用，除非效果明确将其恢复。
Active Slot · 主动插槽
存放可在之后使用的技能骰子或防御骰子。主动插槽中的骰子通常可被敌人技能移除。
Locked Slot · 锁定插槽
存放可以跨回合保留的骰子。只有带锁定插槽位置或允许锁定的结果才能放入。
BP · Backup Plan · 备选方案
使用本回合掷出的骨头结果触发角色垫上的能力。除非技能允许，骨头不能留到下一回合。
Strongest / Weakest · 最强 / 最弱
按当前生命筹码数量比较；平手时通常由当前行动方或规则指定方式决定。
Melee / Ranged · 近战 / 远程
近战单位通常只能以相邻敌人为目标；远程单位通常可攻击非相邻目标，但仍受技能和战斗面板位置限制。

战斗流程

总流程
战斗前 → 设置战斗 → 战斗开始 → 本轮开始 → 各单位依行动顺序执行回合 → 本轮结束 → 本轮结束后补充敌人 → 重复，直到所有敌人或所有基尔洛克被击败 → 战斗结束。
基尔洛克回合
1. 回合开始；2. 移动基尔洛克；3. 指定目标；4. 选择并投掷骰子；5. 以任意顺序结算目标伤害与效果、非目标伤害与效果，并分配主动插槽、锁定插槽和备选方案骰子；6. 敌人反应；7. 回合结束。战利品可在自己回合中的任意时点使用。
敌人回合
1. 回合开始；2. 指定一个或多个目标；3. 移动；4. 结算技能；5. 投掷骰子；6. 依次放置防御骰子、对目标造成伤害、结算触发型技能和暴君骰；7. 基尔洛克反应；8. 回合结束。
时点优先
先处理“回合开始”效果，再移动、指定目标和投骰；“回合结束”效果最后处理。同一时点有多个效果时，按卡牌或技能的明确要求结算。

常见状态与效果骰

状态速查规则
流血
Bleed		在目标上放置流血效果骰。目标每次回合开始受到1点真实伤害，通常持续整场战斗。
混乱
Confuse		交换目标的攻击属性与防御属性；再次施加时移除该效果。
呆滞
Daze		暂译。持续到目标下个回合结束；目标在该回合不能移动。
中毒 #
Poison #		目标回合开始受到等于效果骰数值的真实伤害，之后将效果骰数值降低1。
眩晕
Stun		目标失去下一个回合；回合开始时生效的负面效果仍会结算。
虚弱 #
Weaken #		基尔洛克下回合的敏捷降低#；其他单位的攻击数值降低#。
嘲讽
Taunt		持续到该单位下回合开始。相邻敌对单位必须攻击它；多目标攻击可能多次以它为目标。
恐慌
Terrify		攻击带有恐慌的单位后，攻击者直到下回合结束前不能再以任何带恐慌技能的单位为目标。
无法被指定
Untargetable		不能成为敌对单位的目标，但仍会受到不需要指定目标的技能和范围效果伤害。
飞行
Flight		飞行期间不能成为目标，但仍会受到非指定目标效果。该单位回合结束时通常切换飞行状态。
诱饵 #
Decoy #		敌人被击败时，在其位置放置#生命的诱饵。诱饵存在时，基尔洛克不能攻击其他敌人。
恶臭 #
Stench #		作为无法被指定的障碍留在位置上；放置时对相邻单位造成#真实伤害，基尔洛克移动到其相邻位置还会受到1真实伤害。
熔岩
Lava		由遭遇或技能创建的危险位置。进入、停留或回合结算时的效果以对应规则为准。

激怒

狡猾

引爆 #
Detonate #		移动阶段结束时，若生命未满，该单位击败自己，并对所有相邻单位造成#点真实伤害。
扰乱
Disruption		轮次结束时，将轮次计数骰直接推进到第5轮。
俯冲
Dive		回合开始时若处于飞行状态，立即放到可用的最弱敌对单位相邻位置，并将其作为目标。
闪避
Dodge		该单位的生命不能被攻击骰减少。
吞没

喷发

装备

吸焰 #
Flame Soak #		从熔岩位置上最近的基尔洛克移除#生命并放到本单位下方，可超过生命上限；没有符合目标时尝试选择最近的熔岩敌人。
逃跑
Flee		第2轮和第5轮结束时移出战斗面板并放入已击败堆；若因此离场，最近且持有战利品的敌对单位弃1张战利品。
狂乱 #
Frenzy #		若至少#颗攻击骰命中，再掷#颗攻击骰，并将两次投掷伤害相加。
坚韧

鼓舞 #

压迫 #

反击 #

熔岩流

捣蛋 #

熔岩浴 #
Molten Bath #		若位于熔岩，回合开始恢复#生命；每次移动到熔岩位置时也恢复#生命。

Pollute #		所有不在熔岩位置的基尔洛克获得#级中毒。

Reach		回合开始时，若可以，将最近且尚未相邻的敌对单位放到相邻空位；有相邻熔岩位置时必须优先放到熔岩。

遭遇、奖励与恢复

术语速查规则
持续
Persistent		将卡牌放在暴君卡旁；效果持续到本次冒险结束，或直到规则指定的时点。
突袭
Surprise		设置本场行动顺序后，将所有敌对单位移到行动顺序条底部，保持彼此相对顺序。
受袭
Surprised		设置行动顺序后，只将带有受袭状态的单位移到行动顺序条底部，保持彼此相对顺序。
训练点
Training Point		可解锁技能骰、增加生命或敏捷，或尝试训练攻击/防御属性。
普通战利品
Loot		通常可在自己回合的任意时点使用；恢复阶段可在队员间自由交易。
宝库战利品
Trove Loot		需要依次解开杠杆、机关与蛮力三类锁。已打开的锁会在之后的尝试中保持打开。
休息恢复
Rest and Recover		恢复阶段的个人选项之一：将生命恢复至满值。
寻找战利品
Search for Better Loot		弃1张战利品并掷6颗攻击骰；按命中数量展示战利品，最多保留1张。
侦察
Scout the Area		掷D6查看对应等级敌人；查看后可以将该敌人移到主动敌人堆底部。
开锁重掷
Re-roll		重掷1颗行动骰和直觉骰；若再次掷出重掷，可继续执行。
开锁转换
Convert		将1颗行动骰的锁型视为杠杆、机关或蛮力中的任意一种。
保留 +1
Save +1		使1颗行动骰结果+1；若该骰用于当前锁，不将其耗尽。
